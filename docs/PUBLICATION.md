# Public source and desktop builds

Public repository: https://github.com/brunoloff/MoneyTracker

The original development folder also holds private legacy data and raw bank
exports. Its public Git checkout is kept separately in `.public-repo/`.
The initial commit was made from an audited source-only copy, without importing
any previous history. The public checkout includes the Flutter app, Dart core,
synthetic tests, packaging instructions, and the legacy Python implementation.

Bank keys, `.private/`, CSV exports, ordinary XLSX files, databases, caches, and
generated builds are excluded. `core/test/fixtures/cgd_synthetic.xlsx` is the
explicit workbook exception: it is generated by
`scripts/generate_dart_fixtures.py` from fictional rows. Test images also contain
fictional data. Keep new test fixtures synthetic.

When publishing changes from this development folder, copy only the intended
source files into `.public-repo/`, review the staged diff there, and commit and
push from that checkout. Never copy the entire original directory into Git.
For an ordinary fresh GitHub clone, work directly in the clone. No credentials
are needed to build or run tests.

## GitHub Actions

`.github/workflows/desktop.yml` builds Windows x64 and Linux x64 with the pinned
Flutter SDK. Each platform runs core analysis/tests, Flutter analysis/tests,
and a release build. Windows additionally extracts the packaged ZIP, launches
the executable with a temporary data folder, checks that its window and native
storage initialize, and verifies a clean window close. This is a startup check;
real bank authorization and interactive use on recipients' computers still
need separate testing.

The workflow uses standard GitHub-hosted runners, which are free for public
repositories. It does not use larger runners, provider secrets, personal data,
or real bank requests. Build archives contain the application and instructions.
The startup test creates its data outside the extracted application directory.

Successful runs expose archives under Actions → Desktop packages → Artifacts.
Public release downloads, when published, are at:
https://github.com/brunoloff/MoneyTracker/releases

Extract the entire Windows ZIP and run `money_tracker.exe`; keep all companion
DLLs and the `data/` directory beside it. Each recipient supplies their own
Enable Banking application and key through the app's setup screen.
